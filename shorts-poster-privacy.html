Shorts Poster

Home page and privacy policy · Last updated: November 9, 2026

"Shorts Poster" is a private, internal tool. It runs on one computer and uploads short vertical videos (YouTube Shorts) to a single YouTube channel, মানার জন্য জানা (youtube.com/@manarjonnojana1), with the permission of that channel's owner. It is not offered to the public, and no one else can sign in to it. It is set up and maintained by Ampplify Academy (Rakiza Company LTD).

What the tool does

  • Takes long videos that the channel owner places in a folder on the computer.
  • Cuts them into short vertical clips and writes a title, description and hashtags.
  • Uploads those clips to the channel above on a schedule.

What Google data it uses

When the channel owner signs in with Google, the tool asks for permission to:

  • Upload videos to the owner's YouTube channel (YouTube Data API, upload scope).
  • Read basic channel information (channel name, channel ID and the list of recent uploads), only to confirm it is posting to the correct channel and to avoid uploading the same video twice.

It does not read comments, subscribers, analytics, email, contacts, or any other Google data, and it does not access any other person's account.

How the data is stored

  • The sign-in token is stored only on the computer where the tool runs, inside the automation software's encrypted credential store.
  • A small local log keeps the title, date and video ID of each upload.
  • Nothing is stored on our servers, sold, shared with third parties, or used for advertising.
  • Video clips are sent to Google's Gemini API only to choose the best parts and write titles.

Google API Services User Data Policy

Shorts Poster's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Use of YouTube is also subject to the YouTube Terms of Service and the Google Privacy Policy.

Removing access

The channel owner can stop the tool at any time by removing "Shorts Poster" at myaccount.google.com/permissions. Once access is removed, the stored token no longer works. On request we delete the local token and upload log.
